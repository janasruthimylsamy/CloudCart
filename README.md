# 🛒 CloudCart — Modern E-Commerce Shopping App

A modern, responsive e-commerce shopping application built using **React, TypeScript, Vite, and Tailwind CSS**.

CloudCart provides an interactive online shopping experience where users can explore products, browse categories, manage their shopping cart, and experience a streamlined checkout interface.

🌐 **Live Demo:** https://cloud-cart-delta.vercel.app/
💻 **GitHub Repository:** https://github.com/janasruthimylsamy/CloudCart

---

## ✨ Features

- 🛍️ **Product Catalogue** — Browse a collection of products across multiple categories.
- 🔎 **Product Discovery** — Explore products through an intuitive shopping interface.
- ❤️ **Wishlist** — Save favourite products for later.
- 🛒 **Shopping Cart** — Add, remove, and manage selected products.
- 💳 **Checkout Interface** — Interactive checkout experience.
- 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- 💾 **Local Storage** — Retains supported shopping data in the browser.
- 🎨 **Modern UI** — Clean layouts, interactive elements, and responsive styling.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/janasruthimylsamy/CloudCart.git
```

### 2. Navigate to the Project Folder

```bash
cd CloudCart
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

If the default port is unavailable, use:

```bash
npm run dev -- --port 5173
```

Open the local URL displayed in your terminal.

---

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

---

## ☁️ Deployment

CloudCart is deployed using **GitHub Pages** with an automated **GitHub Actions** workflow.

The deployment process includes:

1. Fetching the latest source code.
2. Installing project dependencies.
3. Building the React application using Vite.
4. Uploading the production files.
5. Publishing the website through GitHub Pages.

**Live Website:** https://janasruthimylsamy.github.io/CloudCart/
